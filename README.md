# validation-api-extension

独立的 Jakarta Validation 扩展组件，提供允许值、数字、日期字符串和国际电话号码校验注解及校验器。

## 版本线

| 分支 | Java | Jakarta Validation | 组件版本 |
| --- | --- | --- | --- |
| `feature/1.0.x` | 8 | 3.0.2 | `1.0.x.20260630-SNAPSHOT` |
| `feature/2.0.x` | 17 | 3.1.1 | `2.0.x.20260630-SNAPSHOT` |
| `feature/3.0.x` | 21 | 3.1.1 | `3.0.x.20260630-SNAPSHOT` |

```xml
<dependency>
    <groupId>io.github.hiwepy</groupId>
    <artifactId>validation-api-extension</artifactId>
    <version>2.0.x.20260630-SNAPSHOT</version>
</dependency>
```
